# Proyecto Final: Base de Datos I

Este repositorio contiene los entregables del proyecto final de la asignatura Tecnología de Base de Datos I.

## Contenido
*   **informe_final.md:** El informe técnico detallando la migración de la base de datos `employees` de MariaDB a PostgreSQL, incluyendo todos los comandos, salidas y análisis de resultados.
*   **Backup Final:** El archivo de respaldo de la base de datos migrada (`backup_final_employees.tar.gz`) se encuentra disponible en la sección de [Releases](https://github.com/carlitos0306/ProyectoFinal_BD1./releases/tag/v1.0) de este repositorio.
